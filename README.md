# Navigation Filter
Um filtro de Kalman é um algoritmo matemático usado para estimar o estado real de um sistema dinâmico (posição, velocidade, etc.) a partir de medições ruidosas e de um modelo matemático do sistema, avaliando o erro do estado estimado e o estado verdadeiro. Isso é feito por meio da fusão de dados vindos de sensores e algoritmos de localização e mapeamento diversos. Dentro do nó desse pacote temos callbacks de pose, twist e odom:

## Pose Callback
Pose callback armazena todas as mensagens vindas do algoritmo de ORBSLAM
